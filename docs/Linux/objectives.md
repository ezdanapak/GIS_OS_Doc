# სასერტიფიკატო ამოცანები

ეს გვერდი ორ საქმეს აკეთებს:

1. **ფარვის რუკა** — რომელი ოფიციალური ამოცანა რომელ თავშია ახსნილი.
2. **პროგრესის ტრეკერი** — მონიშნე უჯრა, როცა თემას დაასრულებ. მთელი მომზადება ერთ გვერდზე ჩანს.

!!! tip "როგორ მონიშნო"
    უჯრები ტექსტშია ჩაწერილი. მონიშვნისთვის ფაილში `- [ ]` შეცვალე `- [x]`-ით
    და ცვლილება ატვირთე. ასე პროგრესი Git-ის ისტორიაშიც ჩაიწერება.

**წონა** = რამდენ კითხვას ელოდები გამოცდაზე. LPIC-1-ის თითო გამოცდაზე ჯამური წონა 60-ია.
მაღალწონიან თემებს მეტი დრო დაუთმე.
