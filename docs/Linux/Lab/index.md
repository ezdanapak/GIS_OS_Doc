# ლაბორატორიები

RHCSA **პრაქტიკული** გამოცდაა — ცოცხალ სისტემას გაძლევენ და ამოცანებს ასრულებ ტაიმერზე.
კონსპექტის კითხვა ამისთვის არ კმარა. აქ თავმოყრილია სცენარები, რომლებიც ხელით უნდა გააკეთო.

!!! tip "როგორ იმუშაო ლაბზე"
    1. აიღე **სუფთა** ვირტუალური მანქანა (snapshot აუცილებლად).
    2. ჩართე ტაიმერი.
    3. გადაწყვეტა ჯერ **დახმარების გარეშე** სცადე — `man` და `--help` დაშვებულია, ინტერნეტი არა (გამოცდაზეც ასეა).
    4. მხოლოდ ამის შემდეგ ნახე პასუხი.
